# Porsche Concept Landing Page

Rediseño conceptual y desarrollo frontend de una landing page inspirada en Porsche.

## Objetivo

Transformar un proceso previo de boceto, wireframe y mockup en una página web funcional, responsive e interactiva.

El proyecto será desarrollado como una práctica de:

- UX/UI.
- HTML semántico.
- CSS.
- JavaScript.
- Accesibilidad web.
- Diseño responsive.
- Git y GitHub.

## Tecnologías

- HTML5.
- CSS3.
- JavaScript.
- Git.
- GitHub.

## Estado del proyecto

Configuración inicial completada.

## Estructura prevista

- Navegación principal.
- Hero de vehículo destacado.
- Servicios.
- Exploración de modelos.
- Comparador de vehículos.
- Sección de asesoramiento.
- Footer.

## Documentación UX/UI

La carpeta `docs` contendrá:

- Bocetos.
- Wireframes.
- Mockups.
- Definición del usuario.
- Objetivos del proyecto.
- Decisiones de diseño.
- Pruebas y mejoras.

## Aviso

Este es un proyecto conceptual no oficial, desarrollado con fines educativos y de portafolio. No está afiliado, respaldado ni administrado por Porsche AG.
